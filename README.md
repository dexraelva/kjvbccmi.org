# KJV Bible Christian Church Website

A complete responsive static website for KJV Bible Christian Church and Ministries Inc.

## Pages included

- Home
- About Us
- Ministries
- Events
- Churches / Branches
- Blog
- Contact
- Donate Now

## How to preview

Serve the project from its root folder, then open `/` in your browser. For example:

```bash
npx serve .
```

Pages use clean folder routes such as `/about/`, `/events/`, and `/contact/`.

## How to edit

- Main styling: `assets/css/styles.css`
- Mobile menu/forms script: `assets/js/main.js`
- Replace placeholder text, schedules, addresses, branch names, donation details, and contact details inside each HTML file.

## Forms

The contact and prayer request forms are front-end demo forms only. Connect them to Formspree, Zoho CRM, Google Forms, a PHP mailer, or another backend before using them live.
